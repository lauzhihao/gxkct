# 爬虫对接 API 文档

## 概述

本文档描述爬虫系统如何与商品处理系统对接。爬虫通过轮询 API 获取任务，执行爬取后提交数据。

**接口地址：** `http://154.12.50.203:8000`

---

## 接口列表

| 接口 | 方法 | 说明 |
|------|------|------|
| `/api/crawler/pending` | GET | 获取待执行任务 |
| `/api/crawler/submit` | POST | 提交爬取结果 |
| `/api/tasks/{task_id}` | GET | 查询任务状态（可选） |

---

## 1. 获取待执行任务

爬虫定时轮询此接口获取新任务。

### 请求

```
GET /api/crawler/pending
```

### 请求参数

无

### 响应

```json
[
  {
    "task_id": "a1b2c3d4",
    "keyword": "wireless earbuds",
    "count": 10
  }
]
```

### 响应字段说明

| 字段 | 类型 | 说明 |
|------|------|------|
| task_id | string | 任务唯一标识，提交结果时需要 |
| keyword | string | 搜索关键词 |
| count | integer | 需要爬取的商品数量 |

### 示例

```bash
curl -X GET "http://154.12.50.203:8000/api/crawler/pending"
```

---

## 2. 提交爬取结果

爬虫完成爬取后，调用此接口提交商品数据。

### 请求

```
POST /api/crawler/submit
Content-Type: application/json
```

### 请求参数

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| task_id | string | 是 | 任务ID（从 pending 接口获取） |
| products | array | 是 | 商品数据数组 |

### products 数组中每个商品的字段

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| product_id | string | 是 | 商品ID（速卖通商品ID） |
| product_url | string | 否 | 商品链接 |
| title | string | 是 | 商品标题 |
| current_price | string | 否 | 当前价格，如 "$36.81" 或 "$10.99 - $25.99" |
| original_price | string | 否 | 原价，如 "$81.80" |
| shipping | string | 否 | 运费信息，如 "Free shipping" 或 "+$2.99 shipping" |
| images | array[string] | 否 | 商品图片URL数组 |
| selling_points | array[string] | 否 | 商品卖点/特性数组 |
| description | string | 否 | 商品描述文本 |
| specifications | array[object] | 否 | 商品规格参数 |
| sku_options | array[object] | 否 | SKU选项（颜色、尺寸等） |

### specifications 数组格式

```json
[
  {"property": "Category", "value": "Earphones & Headphones"},
  {"property": "Brand", "value": "Generic"},
  {"property": "Material", "value": "Plastic"}
]
```

### sku_options 数组格式

```json

  {

    "options": [
```

## 3. 查询任务状态（可选）

爬虫可以查询任务当前状态。

### 请求

```
GET /api/tasks/{task_id}
```

### 请求参数

| 参数 | 位置 | 类型 | 说明 |
|------|------|------|------|
| task_id | path | string | 任务ID |

### 响应

```json
{
  "id": "a1b2c3d4",
  "keyword": "wireless earbuds",
  "count": 10,
  "enable_text_ai": true,
  "enable_image_ai": true,
  "status": "processing",
  "progress": 5,
  "total": 10,
  "created_at": "2024-01-15T10:30:00",
  "updated_at": "2024-01-15T10:35:00",
  "error_message": null
}
```

### 状态说明

| 状态 | 说明 |
|------|------|
| pending | 等待爬虫获取并执行 |
| crawling | 爬虫正在爬取（可选状态） |
| processing | 系统正在处理（AI文案/图片） |
| completed | 处理完成，可下载 |
| failed | 处理失败 |

```python
import time
import requests

API_BASE = "http://154.12.50.203:8000"


def get_pending_tasks():
    """获取待执行任务"""
    try:
        resp = requests.get(f"{API_BASE}/api/crawler/pending", timeout=10)
        resp.raise_for_status()
        return resp.json()
    except Exception as e:
        print(f"获取任务失败: {e}")
        return []


def submit_products(task_id, products):
    """提交爬取结果"""
    try:
        data = {
            "task_id": task_id,
            "products": products
        }
        resp = requests.post(
            f"{API_BASE}/api/crawler/submit",
            json=data,
            timeout=60
        )
        resp.raise_for_status()
        result = resp.json()
        print(f"提交成功: {result}")
        return True
```

## 注意事项

1. **轮询频率**：建议 30 秒轮询一次，避免请求过于频繁

2. **超时设置**：建议设置合理的请求超时时间（10-60秒）

3. **错误重试**：网络请求失败时应该进行重试

4. **数据完整性**：
   - `product_id` 和 `title` 是必填字段
   - 尽量提供完整的商品信息以获得更好的处理效果
   - 图片 URL 需要是可访问的完整地址

5. **图片格式**：支持 jpg、png、webp 格式，不支持 avif

6. **任务状态**：提交数据后任务会自动开始处理，无需额外操作
