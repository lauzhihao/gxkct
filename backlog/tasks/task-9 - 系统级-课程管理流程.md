## Description

实现课程管理流程:

1. 院系管理员负责管理专业,指定专业负责人A(允许多选);
2. 由A编辑专业基础信息、毕业要求及指标点;
3. 由A指定每个指标点对应的课程(如课程尚未创建则引导创建课程),指定任课老师B(允许多选);
4. B负责完善课程基础信息,完成课程矩阵与项目矩阵的建设。
